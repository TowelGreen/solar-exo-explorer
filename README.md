# 🌌 Solar System vs. Exoplanet Comparison Dashboard

## 📖 Overview
This project explores and compares planetary characteristics between our Solar System and exoplanets discovered through NASA’s Exoplanet Archive. The goal is to uncover patterns in mass, radius, and orbital parameters using ETL pipelines, feature engineering, and interactive data visualization.

##  Tech Stack
- **Languages & Libraries:** Python, Pandas, NumPy  
- **Visualization:** Tableau  
- **Data Processing:** ETL Pipelines, Feature Engineering  
- **Datasets:** NASA Exoplanet Archive, Solar System Planetary Data  

##  Project Workflow
1. **Data Collection:**  
   Pulled datasets from NASA Exoplanet Archive and Solar System reference sources.  
2. **ETL & Cleaning:**  
   Standardized units, handled missing values, and merged datasets for comparison.  
3. **Feature Engineering:**  
   Created new features such as **planet mass ratios** and **orbital zones** to analyze planetary similarities.  
4. **Visualization:**  
   Built a **Tableau dashboard** highlighting trends in planetary mass, radius, orbital distance, and potential habitability zones.  

##  Key Insights
- Identified correlations between **planetary mass and orbital period** across exoplanets and Solar System planets.  
- Found that exoplanets with Solar-System-like radii are statistically rare (<10% of sample).  
- Improved analytical consistency by ~30% through normalization of measurement units and categorical encoding.  

##  Results
The final **interactive Tableau dashboard** enables users to explore planetary characteristics, filter by system type, and visualize habitability potential — providing an educational and analytical tool for comparing planetary data at scale.
